# Upollo

Upollo is a startup founded by Cayden Meyer and backed by Index Ventures that helped subscription businesses find and convert repeat trialers, account sharers, and other high-intent users. Its detection surface was reachable through integrations such as a Segment browser destination action and Pipedream API components.

As of July 2026 the enrichment pipeline found: the primary domain upollo.ai no longer resolves (no A/NS/SOA/MX records); upollo.dev and upollo.com are parked at third-party registrar/marketplace nameservers; the github.com/upollo organization exists but has no public repositories; and the only first-party package remaining in public registries is the `ai.upollo:upollo-android` AAR on Maven Central (last published 2022-12-15). No live API surface is currently published to capture.
